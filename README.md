# 幼小衔接每日学习(单文件网页 App)

打开 `index.html` 即可使用:手机浏览器、电脑浏览器都行,**不需要联网、不需要账号、没有广告和内购**。
进度存在浏览器的 localStorage 里。

## 怎么在手机上用
1. 把 `index.html` 放到任意能打开网页的地方(自己的网站 / 网盘直链 / 局域网静态服务器 / 手机文件管理器里直接用 Chrome 打开)。
   - 直接 `file://` 打开时,部分手机浏览器不保存进度(页面会提示)。**更稳妥:用 http(s) 地址打开。**
2. 浏览器菜单 →「添加到主屏幕」,以后点桌面图标就能玩。(没有做离线 PWA/service worker,所以图标只是网页快捷方式。)
3. 朗读(🔊)用的是手机自带的中文语音(`speechSynthesis`,zh-CN)。没声音时,在手机设置里安装/开启「文字转语音」中文语音。设备完全不支持时,朗读按钮自动隐藏。

## 内容
- 30 天课程,4 个主题周(声母小镇 / 韵母乐园 / 拼读大冒险 / 小学预备营)+ 第 29、30 天毕业复习;每周第 6 天复习日、第 7 天挑战日。30 天后自动进入"复习轮"。
- 每天 3/4/5 关(家长区可选,默认 5 关,每关约 4 分钟),关间有奖励/休息页面。
- 拼音:声母、韵母、看图选声母/韵母、拼读、大小写、连连看、看图说话。
- 识字:100 个常用字(选字、听音找字、字音配对、看图识字、反义字、笔画数/笔顺、描红 24 个字)。
- 古诗:《静夜思》《春晓》《咏鹅》《登鹳雀楼》,每周一首(读一读 + 填字 + 接下一句 + 作者)。
- 数学(v2,只做加法,**没有任何减法题**):凑十(几和几是 10)→ 十加几(10+3=13)→ 9+几 / 8+几 …… 凑十法进位加(分 3 步:拆 → 凑十 → 加,带十格框图示)→ 20 以内加法综合 → 整十数加法(10+20、30+20,结果不超过 100,带"几个十"图示)→ 整十加几(20+3)→ 加法应用题 → 混合复习;另有数数、比大小、图形、位置、数序、找规律、认整点、数到 100。每种题都有图示提示,轻松/标准/挑战三档难度会改变数字范围和选项数。
- 逻辑:找不同、分类、找不一样的、翻牌记忆、走迷宫(v2 每天只保留 1 道,腾出时间给数学和字母)。
- 英语(v2,26 个字母):每天一关"字母小屋"。字母卡(大写+小写+关键词表情,点一点用 `speechSynthesis`(en-US)读字母名)+ 跟读小达人(随机字母,🔊 听一听 / 再读一遍 / 下一个字母,不用语音识别)+ 小游戏:听音选字母、大小写选择/配对、找不同(b/d、p/q 等易混)、字母顺序、看图选首字母。第 1~11 天每天 2~3 个新字母(A–Z 全部学完),第 12~26 天轮流复习易混字母对(b d / p q / m n / i j / a e 等),主角是字母名,自然拼读首音只是家长区可开的"小耳朵 👂"。设备没有英文语音时自动显示"请爸爸妈妈读"的文字提示。
- 每天一个"今日小任务"(家长打勾)+ 家长每日 2 分钟配合提示。
- 激励:星星、30 张贴纸(完成一天得一张)、连续天数、会成长的小宠物(神秘蛋 → 神奇小马)。答错不扣分,有温和提示,可以再试;答错的题会在本关结尾再出现一次。
- 题目由程序按"当天内容 + 难度"生成,用日期做种子:每天不同,同一天刷新题目不变。
- 家长区(做 6~9 的乘法题进入):学习概况、各科正确率、每天记录、难度(轻松/标准/挑战)、每天关卡数、音效/朗读开关、从第几天开始、备份导出/导入(复制粘贴 JSON)、清除进度。
- 重玩已完成的日子(地图里点)算"练习":给星星,但不影响统计、连续天数和贴纸。

## 如何修改
源码在 `src/`,用 `python3 src/build.py` 合成 `index.html`(路径按脚本位置自动推算,输出到项目根目录的 `index.html`)。

| 想改什么 | 改哪个文件 |
|---|---|
| 词语/识字表/古诗/贴纸/宠物阈值/小任务/家长提示 | `src/10_data.js`(`WORDS`、`CHAR_PLAN`、`POEMS`、`STICKERS`、`PETS`、`HABITS`、`TIPS`(家长"今日提示")、`LETTERS`(26 字母数据)、`LTR_NEW`/`LTR_RE`(每天学/复习哪些字母)) |
| 30 天安排(每天学哪几个声母/韵母/字,数学何时解锁) | `src/40_curr.js`(`INIT_NEW`、`FIN_NEW`、`MATH_UNLOCK`、`OUTLINE`、`levelPlan`) |
| 出题逻辑 | `src/30_gen.js`(通用题)、`src/32_math_add.js`(凑十/十加几/进位加/整十加法,全部为加法)、`src/34_gen_en.js`(字母题),每种题一个 `gXxx` 函数,返回 `meta` 便于自动校验 |
| 页面/按钮/流程 | `src/60_ui.js`;样式 `src/05_style.css` |

改完后建议跑 `tests/`(Python Playwright + Chrome):
- `gen_test.py`(+ `validate.js`):生成全部 30 天 × 3 档难度 × 3/4/5 关的题目并逐题校验——每道加法答案正确、选择题恰好一个正确选项、没有任何减法题(扫描文字/符号/题型)、整十数加法结果 ≤ 100、凑十分步答案正确、字母题答案/大小写/顺序正确、26 字母 30 天内全覆盖;
- `render_test.py`:每种题逐个渲染,不能有 undefined/NaN/报错;
- `flow_test.py`、`play_test.py`:完整一天的交互(含答错重试、分步凑十、跟读)、家长区、无存储降级;
- `migrate_test.py`:旧版(v1)存档升级——不白屏、星星/贴纸/宠物保留;
- `shots2.py`:390×844 截图并检查横向溢出和按钮大小。

调试:网址后加 `?now=2026-11-03` 可模拟日期;控制台里 `KID` 对象可查看/修改状态。
