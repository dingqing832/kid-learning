# 幼小衔接每日学习(单文件网页 App)

打开 `index.html` 即可使用:手机浏览器、电脑浏览器都行,**不需要联网、不需要账号、没有广告和内购**。
进度存在浏览器的 localStorage 里。

## 怎么在手机上用
1. 把 `index.html` 放到任意能打开网页的地方(自己的网站 / 网盘直链 / 局域网静态服务器 / 手机文件管理器里直接用 Chrome 打开)。
   - 直接 `file://` 打开时,部分手机浏览器不保存进度(页面会提示)。**更稳妥:用 http(s) 地址打开。**
2. 浏览器菜单 →「添加到主屏幕」,以后点桌面图标就能玩。(没有做离线 PWA/service worker,所以图标只是网页快捷方式。)
3. 朗读(🔊)用的是手机自带的中文语音(`speechSynthesis`,zh-CN)。没声音时,在手机设置里安装/开启「文字转语音」中文语音。设备完全不支持时,朗读按钮自动隐藏。

## 内容(v3:数学 + 自然拼读 + 写数字)
- 30 天课程,5 个主题周(数字小学堂 / 凑十乐园 / 进位加法营 / 整十加法营 / 毕业典礼);每周第 6 天复习日、第 7 天挑战日。30 天后自动进入"复习日"。
- 每天 3/4/5 关(家长区可选,默认 5 关,每关约 4 分钟),关间有奖励/休息页面。默认 5 关:数学乐园 → 字母拼读屋 → 加法训练营 → 写数字 → 小小挑战(数学 + 拼读 + 写数字 + 1 道逻辑)。
- **数学(只做加法,没有任何减法题)**:数数/分合 → 10 以内加法 → 凑十 → 十加个位数(10+3)→ 9/8/7/6+几 的凑十法进位加(拆 → 凑十 → 加,带十格图)→ 20 以内加法 → 整十数加法(10+20、30+20)→ 整十加几(20+3)→ 应用题/综合。每个阶段解锁后持续巩固,难度逐步上升,结果不超过 100。
- **自然拼读(字母的"声音",不是字母名)**:每天"字母拼读屋"先认字母名(A 叫 /eɪ/),再学"声音":大卡片显示字母 + 关键词图 + 音标,按钮 🔊 听拼读 / 🔁 再听一次 / 🐢 再慢一点 / 🗣 我来跟读。播放顺序:字母名 → 停 1 秒 → 声音 ×2 → "A says /æ/ as in apple"。慢速 en-US `speechSynthesis`,元音用 ah/eh、辅音用短促的 buh/kuh/duh 近似,界面提示"轻轻读"。游戏"找拼读":听声音选字母 / 看字母选关键词图;答对有奖励,答错温和提示并慢速重放。26 个字母 11 天内全部学完,之后按易混组(b/d/p/q、m/n、c/k、a/e/i 等)反复练习。
- **写数字**:每天都有。先 1–9(前 4 天),再 0、10–20;描红时有笔顺、起笔点和方向箭头,完成有星星奖励(Canvas,支持触摸)。还有数一数、数字后面是几、补缺的数、认镜像字等小题。
- 逻辑:每天只保留 1 道找不同/分类/记忆/迷宫,当"小调剂"。
- 每天一个"今日小任务"(家长打勾)+ 家长每日 2 分钟配合提示。
- 激励:星星、30 张贴纸、连续天数、会成长的小宠物。答错不扣分,有温和提示,可以再试。
- 题目由程序按"当天内容 + 难度"生成,用日期做种子:每天不同,同一天刷新题目不变。
- 家长区(做 6~9 的乘法题进入):学习概况、各科正确率、每天记录、难度、每天关卡数、音效/朗读开关、从第几天开始、备份导出/导入。
- 重玩已完成的日子(地图里点)算"练习":给星星,但不影响统计、连续天数和贴纸。

### 默认课程里去掉了什么(代码和数据都还在)
拼音(声母/韵母/拼读)、识字、古诗、汉字描红 不在默认的每日课程里。需要恢复时,把 `src/40_curr.js` 里的 `COURSE_MODE='focus'` 改成 `'legacy'` 再运行 `python3 src/build.py` 即可回到 v2 的课程安排(`WEEKS_LEGACY / OUTLINE_LEGACY / MATH_UNLOCK_LEGACY / levelPlanLegacy / TIPS_LEGACY`)。

## 如何修改
源码在 `src/`,用 `python3 src/build.py` 合成 `index.html`(路径按脚本位置自动推算,输出到项目根目录的 `index.html`)。

| 想改什么 | 改哪个文件 |
|---|---|
| 词语/识字表/古诗/贴纸/宠物阈值/小任务/家长提示 | `src/10_data.js`(`WORDS`、`CHAR_PLAN`、`POEMS`、`STICKERS`、`PETS`、`HABITS`、`TIPS`(家长"今日提示")、`LETTERS`(26 字母数据)、`LTR_NEW`/`LTR_RE`(每天学/复习哪些字母)) |
| 30 天安排(每天学哪几个字母/数字,数学何时解锁) | `src/40_curr.js`(`OUTLINE_FOCUS`、`MATH_UNLOCK_FOCUS`、`levelPlanFocus`);`src/10_data.js`(`LTR_NEW`) |
| 自然拼读 / 写数字数据与出题 | `src/12_phonics.js`、`src/12_digits.js`、`src/36_gen_phonics.js`、`src/38_gen_digits.js` |
| 出题逻辑 | `src/30_gen.js`(通用题)、`src/32_math_add.js`(凑十/十加几/进位加/整十加法,全部为加法)、`src/34_gen_en.js`(字母题),每种题一个 `gXxx` 函数,返回 `meta` 便于自动校验 |
| 页面/按钮/流程 | `src/60_ui.js`;样式 `src/05_style.css` |

改完后建议跑 `tests/`(Python Playwright + Chrome):
- `gen_test.py`(+ `validate.js`):生成全部 30 天 × 3 档难度 × 3/4/5 关的题目并逐题校验——每道加法答案正确、选择题恰好一个正确选项、没有任何减法题(扫描文字/符号/题型)、整十数加法结果 ≤ 100、凑十分步答案正确、字母题答案/大小写/顺序正确、26 字母 30 天内全覆盖;
- `render_test.py`:每种题逐个渲染,不能有 undefined/NaN/报错;
- `flow_test.py`、`play_test.py`:完整一天的交互(含答错重试、分步凑十、跟读)、家长区、无存储降级;
- `migrate_test.py`:旧版(v1)存档升级——不白屏、星星/贴纸/宠物保留;
- `shots2.py`:390×844 截图并检查横向溢出和按钮大小。

调试:网址后加 `?now=2026-11-03` 可模拟日期;控制台里 `KID` 对象可查看/修改状态。

## v3 版本说明
- 框架、奖励、家长区、离线单文件、手机竖屏体验不变,课程聚焦数学加法 + 自然拼读 + 写数字。
- 旧存档兼容:星星、贴纸、连续天数、宠物名都保留;"还没做完的某一天"的关卡进度回到第 1 关重新开始(因为课程换了);老存档没有数字统计时会自动补齐,不会白屏。
- 如何扩展:拼读数据在 `src/12_phonics.js` 的 `PHONICS`(字母 → 音标/朗读用拼写/中文提示;关键词和表情在 `10_data.js` 的 `LETTERS`);写数字的笔画在 `src/12_digits.js`(`DIGIT_GLYPH` 单个数字笔画、`DIGIT_SETS` 0–20,要加更大的数在这里注册即可);哪天学哪些字母/数字在 `src/40_curr.js`(`INIT_NEW/LTR_NEW`、`DIGIT_NEW`)。
- 已知限制:拼读靠手机自带的英文语音,单个音素用 ah/buh 等拼写近似,不同手机的发音不完全准确,家长可示范(应用里已提示);没有语音识别,"跟读"靠孩子自己读;未在真机上测试。
